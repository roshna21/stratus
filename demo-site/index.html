What it does that a code generator doesn't

  • Reads the account first — so asking twice doesn't build twice.
  • Prices the change — which things are free, which bill on usage, and which charge every hour.
  • Refuses unsafe configurations — and sends them back to the model to be rewritten, so you see the safe version rather than an error.
  • Requires the word DELETE before destroying anything.
  • Recovers from half-finished builds — works out what survived, offers to finish or undo.
  • Notices drift — when something changed in the cloud outside of it.
  • Records every change, and can roll back to any of them.

Underneath

Python, Terraform, and one language-model call — for turning an ambiguous sentence into a configuration. Everything else has exactly one correct answer, so it is ordinary code: instant, free, and identical every time.
